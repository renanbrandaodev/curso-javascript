## 📌 Sobre

Este repositório reúne toda a minha prática durante o módulo de JavaScript do Curso em Vídeo, um curso introdutório e gratuito voltado para quem está começando na programação. Ao longo dele, foram trabalhados os seguintes temas:

- Variáveis, tipos de dados e template literals
- Estruturas condicionais (`if`, `else if`, `switch case`)
- Estruturas de repetição (`while`, `do...while`, `for`)
- Arrays e seus principais métodos (`sort()`, `push()`, `indexOf()`, `for...in`)
- Funções (parâmetros padrão, funções anônimas e recursão)
- Objetos, propriedades, métodos e a palavra-chave `this`
- Manipulação do DOM e eventos (`getElementById`, `innerHTML`, `addEventListener`)
- Validação de dados de formulário (`isNaN`, `Number()`)

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)

## ▶️ Como executar

A maioria dos exercícios é composta por arquivos HTML com JavaScript embutido ou vinculado. Para rodá-los localmente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/renanbrandaodev/curso-javascript.git
   ```
2. Abra o arquivo `.html` desejado diretamente no navegador, ou use uma extensão como o **Live Server** (VS Code) para melhor experiência.
3. Para os arquivos `.js` isolados (sem HTML), execute-os com o Node.js:
   ```bash
   node caminho/do/arquivo.js
   ```
